사용 방법

START ENGINE / STOP ENGINE
프로듀서를 시작·정지합니다. 1,000건 누적 시 자동 종료되며 통계 리포트가 표시됩니다.
RESET
완료 후 나타나는 버튼입니다. 모든 카운트와 로그를 초기화합니다.
PRODUCER_INTERVAL
이벤트 발생 간격입니다. 10ms ~ 3,000ms 범위에서 설정합니다.
DB_FAULT
Redis 장애를 발생시킵니다. 직접 DB 적재는 즉시 실패, Kafka 파이프라인은 PENDING 후 복구 시 재처리됩니다.
KAFKA_FAULT
터미널에서 docker stop kafka로 브로커를 내립니다. 브로커 다운 시 Kafka 파이프라인은 DIRECT DB INSERT 모드로 전환됩니다.
DB_FAULT AND KAFKA_FAULT
DB와 Kafka가 동시에 장애 상태인 동안에는 Producer fallback도 실패하여 FAIL로 집계됩니다. 이후 Kafka만 먼저 복구되면 메시지는 Kafka에 적재되어 PENDING으로 전환되고, DB 복구 시 순차 재처리됩니다.
